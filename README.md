# 💀🐍 Skull Snake

Um jogo de **Snake** desenvolvido com **HTML, CSS e JavaScript**, criado como projeto de prática e aprendizado em desenvolvimento web.

O objetivo é simples: **controle a cobra, coma os alimentos, aumente sua pontuação e tente bater o recorde!**

## 🎮 Jogue agora

👉 **[Jogar Skull Snake](https://skullsnake.netlify.app/)**

## 🖼️ Preview

![Skull Snake](preview.png)

## 🕹️ Como jogar

- Use as **setas do teclado** para movimentar a cobra.
- 🍎 Coma os alimentos para aumentar sua pontuação.
- 🐍 A cada alimento coletado, a cobra cresce.
- 💀 Evite as colisões e tente sobreviver o máximo possível.
- 🏆 Tente superar o seu recorde!

## ✨ Funcionalidades

- Sistema de pontuação.
- Sistema de recorde.
- Crescimento da cobra conforme os alimentos são coletados.
- Movimentação em tempo real.
- Detecção de colisões.
- Interface com tema escuro.
- Jogo executado diretamente no navegador.
- Publicação online através do Netlify.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página.
- **CSS3** — estilização e interface.
- **JavaScript** — lógica do jogo, movimentação, pontuação, colisões e atualização do estado.

## 📚 O que pratiquei neste projeto

Este projeto foi desenvolvido para colocar em prática conceitos fundamentais de JavaScript, como:

- Variáveis e constantes.
- Arrays.
- Funções.
- Condicionais (`if / else`).
- Loops.
- Manipulação do DOM.
- Eventos de teclado.
- Temporizadores.
- Lógica de colisão.
- Atualização dinâmica de elementos na tela.
- Organização de um projeto front-end.
